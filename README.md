# Supplementary Data

This repository contains the numerical experiment data accompanying our paper on supply chain network design under intentional attacks.

## Contents

The ZIP archive contains Excel workbooks for:

- **Fig. 5:** MISOCP-B&C convergence.
- **Figs. 7–8:** Robust and non-robust design comparisons.
- **Fig. 9:** Algorithm performance comparisons.
- **Figs. 10–12:** Sensitivity analyses of protection capacity, facility location cost, and node recovery cost.
- **Table 8:** Validation against exhaustive enumeration, including all 400 instances, results by network size, and an overall summary.

## Usage

Download and extract the ZIP archive to access the workbooks. File names correspond to the figures and table in the paper.
